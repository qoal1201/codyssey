# 게임을 만드는 기록

미션 2-1 기획서 초안. 기존 [게임을 만드는 기록](https://game-making-journal.parksunho.chatgpt.site/)을 확인해 작성했습니다. 현재 홈에는 PHONE ARCADE/Handgun 개발 일지 5편이 보입니다.

## 대상 사용자

- 게임을 만들며 생각과 진행 과정을 정리하려는 나.
- 게임 개발 과정과 배운 점을 읽고 싶은 사람.

## 사용 목적

- 아이디어부터 제작과 플레이 확인까지, 게임을 만들며 내린 결정과 배운 점을 날짜순으로 기록합니다.
- 독자는 프로젝트와 날짜를 따라 개발 일지를 읽습니다.

## 화면 구성과 동작

- 위쪽에 블로그 이름과 ‘모든 기록’, ‘소개’ 메뉴가 있습니다.
- 첫 화면에 블로그 소개와 개발 일지 목록이 나옵니다.
- 목록은 오래된 글부터 보여 주며, ‘전체’와 프로젝트 분류로 글을 거릅니다.
- 글 카드에는 날짜, 분류, 제목, 짧은 소개가 나오고 제목을 누르면 글을 읽습니다.
- 글에는 제목, 날짜, 프로젝트·분류, 본문과 목차가 있습니다. 목차를 누르면 해당 부분으로 이동하고, 이전 글과 전체 목록으로 돌아갈 수 있습니다.
- 하단에는 블로그 소개와 홈으로 가는 링크가 있습니다.

## 필요한 자료

- 글마다 날짜, 프로젝트명, 분류, 제목, 짧은 소개, 본문과 소제목.
- 이전·다음 글 연결 정보.
- 그림을 사용할 때는 설명과 대체 텍스트. 실제 화면이 아닌 시안은 시안이라고 표시합니다.
- 결정한 내용, 직접 확인한 결과, 아직 확인하지 못한 내용을 구분해 씁니다.

## 완료 기준

- 첫 화면에서 블로그 소개와 개발 일지 목록을 읽을 수 있습니다.
- 분류를 바꾸면 해당 글만 보이고, 표시된 글 수가 목록과 맞습니다.
- 글 제목을 누르면 맞는 글이 열리고, 목차·이전 글·전체 목록 링크가 동작합니다.
- 글에서 계획과 실제 확인 결과, 미검증 사항을 구분할 수 있습니다.

## 추가 기능

- 현재 별도로 추가할 기능은 정하지 않았습니다.

## 한계 및 비목표

1. 글을 사이트에서 직접 작성·수정하는 기능은 이번 범위에 넣지 않습니다.
2. 로그인, 댓글, 좋아요 기능은 이번 범위에 넣지 않습니다.
3. 기존 글에 없는 내용이나 확인하지 않은 결과를 새 사실처럼 추가하지 않습니다.

## 검증 방법

- 홈의 글 제목·날짜·분류·소개를 각 글과 대조합니다.
- 분류별 글 수와 실제 목록을 비교하고, 글·목차·이전 글·전체 목록 링크를 눌러 확인합니다.
- 본문과 그림 설명에서 계획, 직접 확인, 미검증 상태가 뒤섞이지 않았는지 확인합니다.
