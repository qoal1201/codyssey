## 수정 기록

### 수정 기록 1

- 발견한 문제: 375px 화면에서 글 번호 `01 / 05`가 두 줄로 접혔습니다.
- 수정 요청: 별도 AI 요청은 하지 않았습니다. 현재 CSS의 모바일 번호 열 너비만 조정했습니다.
- 수정 내용: 원본 v1은 유지하고 v2의 420px 이하 화면에서 번호 열을 36px에서 44px로 넓혔습니다.
- 수정 후 테스트 결과: 375px과 320px 화면에서 번호가 한 줄로 보이고 문서·카드에 가로 넘침이 없었습니다.
- 수정 이유: 글 순번을 한눈에 읽을 수 있도록 줄바꿈을 없앴습니다.

## 사용자 테스트

- 참여자와 요청한 작업: 제작자인 사용자가 아래 세 과제를 직접 수행하고 결과를 보고했습니다.
  1. ‘가장 최근 기록을 찾아 원문을 열어 주세요.’
  2. ‘이 사이트가 어떤 기록을 모아 두는지 살펴보고 목록으로 돌아와 주세요.’
  3. ‘Handgun 기록만 보고 싶다면 어떻게 할지 보여 주세요.’
- 행동과 질문: 원문을 열자 실제 사용자가 만든 DB가 연결된 메인 사이트로 이동했습니다. 사용자는 이 페이지가 미션을 위한 정적 HTML이므로 그 동작을 이해한다고 보고했습니다.
- 받은 피드백: 나머지 동작은 모두 정상적으로 작동했다고 보고했습니다.
- 반영 내용과 결과: 원문 링크는 기획에 맞는 실제 글로 이동하므로 변경하지 않았습니다. 다른 수정 요청도 없어 추가 코드는 바꾸지 않았습니다.
- 검증 구분: 제작자의 직접 사용 결과입니다. 제작자 사전 지식이 있으므로 처음 보는 독자의 독립 사용자 테스트와는 구분합니다.
