# 미션 2-3 기획서 수정본: 게임을 만드는 기록

## 결과물 방향

- 미션 2-2의 [게임개발기록_v1.html](../2-2/게임개발기록_v1.html)을 출발점으로 삼습니다.
- 사용자가 정한 방향은 별도의 HTML 복제본을 더 만드는 대신, v1을 발전시킨 결과물로 이미 보유한 실제 기술 블로그를 그대로 사용하는 것입니다.
- 결과물: [게임을 만드는 기록](https://game-making-journal.parksunho.chatgpt.site/)
- 기존 사이트와 미션 2-3의 이전 정적 시안은 보존합니다. 이번 기록을 위해 온라인 사이트를 수정하거나 새 사이트를 공개하지 않습니다.
- 이 방향은 사용자가 설명한 작업 맥락을 기록한 것입니다. 현재 사이트 화면과 동작은 브라우저에서 별도로 확인합니다.

## 대상 사용자

- 게임 개발 기록을 읽고 싶은 사람.
- 제작 과정과 직접 확인한 결과, 남은 질문을 살펴보려는 사람.

## 사용 목적

- 홈에서 다섯 편의 기록을 훑고 원하는 글을 엽니다.
- 글 안에서 사진, 목차, 이전·다음 글을 이용해 개발 과정을 따라갑니다.

## 화면 구성과 동작

- 홈에는 소개, ‘모든 기록’·‘소개’ 메뉴, ‘전체’·‘Handgun’ 필터와 다섯 글 목록이 있습니다.
- 글 카드에는 날짜, 분류, 제목, 짧은 소개, 원문으로 이동하는 링크와 썸네일이 있습니다.
- 글 제목을 열면 해당 글의 본문, 소제목, 사진과 캡션을 볼 수 있습니다.
- 본문 목차는 각 절로 이동하며, 글 아래의 이전·다음 링크와 전체 목록 링크로 탐색을 이어갑니다.
- 좁은 화면에서도 본문과 글 목록을 읽을 수 있어야 합니다. 화면 폭에 따라 목차가 숨겨지는 현재 동작은 한계로 기록합니다.

## 필요한 자료

- 기존 블로그의 다섯 글에 있는 날짜, 분류, 제목, 소개, 원문 주소와 썸네일.
- 각 원문 본문, 목차 항목, 이미지 대체 텍스트와 캡션.
- 필터 상태와 화면 폭별 표시 결과.
- 실제 사용자 테스트에서 관찰한 행동, 질문과 피드백.

## 완료 기준

- 결과물은 별도 복제본이 아니라 기존 기술 블로그 URL로 연결됩니다.
- 다섯 글의 날짜·분류·제목·소개·원문 링크가 홈과 각 원문에서 일치합니다.
- 홈 카드에 다섯 썸네일이 표시되고, 글 링크를 열면 해당 글의 본문이 나옵니다.
- 데스크톱에서 목차 링크가 각 절로 이동하고, 전체 목록 및 이전·다음 글 링크가 동작합니다.
- 필터의 선택 상태·표시 수·목록 수가 맞고, 키보드 포커스가 보입니다.
- 375px 및 320px 화면에서 가로 넘침 없이 글 목록을 읽고 조작할 수 있습니다.
- 실제 사용자 테스트와 제작자 사전 지식 여부를 기록합니다. 브라우저 자동 조작은 사용자 테스트와 구분합니다.
- 아직 실행하지 않은 테스트나 실제 참여자가 없는 사용자 테스트는 완료로 표시하지 않습니다.

## 추가 기능

- 이번 방향에서는 새 기능을 추가하지 않습니다. 기존 블로그에 있는 썸네일, 본문 목차, 사진·캡션, 이전·다음 탐색을 결과물의 기능으로 확인합니다.

## 한계 및 비목표

1. 기존 사이트를 복제하거나 이 저장소에서 다시 구현하지 않습니다.
2. 사용자가 보유한 온라인 블로그의 글, 이미지, 디자인과 동작을 이번 확인 과정에서 변경하지 않습니다.
3. 테스트용 글이나 분류를 임의로 추가하지 않습니다. 현재 다섯 글은 모두 Handgun이므로 두 필터가 같은 다섯 글을 표시합니다.
4. 실제 휴대폰에서의 사용감은 브라우저 모바일 에뮬레이션 결과와 구분합니다.

## 검증 방법

- 홈에서 다섯 카드의 날짜·분류·제목·소개·원문 주소·썸네일을 확인합니다.
- 다섯 원문을 열어 목록 제목과 본문 제목을 대조하고, 목차 링크의 목적지가 있는지 확인합니다.
- 필터를 마우스와 키보드로 선택해 버튼 상태와 표시 글 수를 확인합니다.
- 375px·320px 브라우저 화면에서 문서 너비와 카드·썸네일 표시를 확인합니다.
- 제작자 또는 독자에게 과제를 요청했다면 설명 전 행동과 질문을 관찰해 기록하고, 참여자의 사전 지식을 표시합니다.
- 직접 확인한 브라우저 결과는 [브라우저 검증 근거](evidence/기존기술블로그_브라우저검증_2026-11-09.md)에 기록합니다.
