## 수정 기록

### 기존 기술 블로그를 결과물로 선택

- 발견한 문제: 2-2의 정적 HTML은 글 목록과 원문 링크는 있지만, 기존 블로그의 전체 본문·사진·목차를 직접 보여 주지 않습니다.
- 결정: 사용자는 기존 블로그를 새 시안으로 복제하지 않고 결과물로 그대로 사용하기로 했습니다.
- 수정 내용: 온라인 사이트나 HTML을 편집하지 않았습니다. 기획서와 검증 기록의 기준 결과물을 기존 블로그로 정리하고, 과거 정적 시안은 보존했습니다.
- 확인 결과: 홈 썸네일, 다섯 본문, 목차와 글 간 이동이 실제 사이트에서 확인됐습니다.

### 확인된 한계

- 홈의 다섯 썸네일은 화면에는 보이지만 `alt` 텍스트가 비어 있습니다.
- 320px 화면에서는 본문 목차 영역이 숨겨집니다. 본문 자체는 이어서 읽을 수 있지만 목차를 이용한 이동은 제공되지 않습니다.
- 사용자의 “v1을 발전시킨 결과물이 기존 블로그”라는 작업 맥락은 사용자 설명에 따른 기록입니다. 이 저장소에는 기존 블로그의 배포 소스나 배포 커밋이 없어 해당 연결 관계를 Git으로 재현하지 않았습니다.

## 사용자 테스트

- 참여자와 사전 지식: 제작자인 사용자. 기존 블로그를 알고 있는 참여자의 테스트로, 처음 방문한 독자의 독립 테스트와 구분합니다.
- 요청한 과제: 가장 최근 글 열기, 글 목차로 한 섹션 이동한 뒤 전체 목록으로 돌아오기, Handgun 필터와 썸네일 확인.
- 사용자의 행동과 질문: 사용자는 과제를 직접 해본 뒤 “다 괜찮은데?”라고 보고했습니다. 단계별 세부 행동이나 별도 질문은 보고되지 않았습니다.
- 받은 피드백: 요청한 흐름에서 문제가 없었다는 사용자 보고입니다.
- 반영 내용과 결과: 수정 요청은 없었습니다. 이 결과는 브라우저 자동 확인과 구분해 제작자 사용자 보고로 기록합니다.
- 검증 구분: 실제 첫 방문자의 독립 사용자 테스트는 수행하지 않았습니다.
