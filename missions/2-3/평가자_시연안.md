# 미션 2-3 평가자 시연안

## 30초 소개

“미션 2-2에서 만든 `게임개발기록_v1.html`은 글 목록과 필터, 원문 링크를 갖춘 정적 시안입니다. 다음 단계에서는 제가 이미 운영하던 기술 블로그를 결과물로 사용해 실제 글 본문, 사진 미리보기, 목차와 글 간 이동을 보여 드리겠습니다. 이번 미션에서는 별도 사이트를 만들거나 온라인 블로그를 수정하지 않고, 실제 블로그의 동작을 확인하고 기록했습니다.”

## 3~5분 시연 순서

### 1. 출발점과 결과물 설명

- [미션 2-2의 v1 HTML](../2-2/게임개발기록_v1.html)을 보여 주고, 목록·필터·원문 링크 중심의 시작 버전이라고 설명합니다.
- 이어 [실제 기술 블로그](https://game-making-journal.parksunho.chatgpt.site/)를 엽니다.
- 이번 결과물은 새 복제본이 아니라 사용자가 이미 보유한 블로그라는 점을 분명히 합니다.

### 2. 홈에서 글과 이미지 미리보기

- 다섯 글의 날짜·분류·제목·소개와 오른쪽 썸네일을 보여 줍니다.
- `Handgun`을 눌러 선택 표시와 글 수를 확인합니다. 현재 다섯 글 모두 Handgun이므로 전체와 Handgun 결과가 각각 5편입니다.
- 설명 예시: “카드에서 글의 주제와 이미지를 먼저 보고, 제목이나 기록 읽기를 선택하면 실제 글로 이동합니다.”

### 3. 실제 글, 목차와 글 간 탐색

- 가장 최근 글을 엽니다.
- 본문과 사진·캡션을 간단히 보여 준 뒤 데스크톱 목차에서 항목 하나를 선택해 해당 절로 이동합니다.
- 하단의 이전/다음 글과 전체 목록으로 돌아가는 링크를 보여 줍니다.
- 설명 예시: “홈 카드만 있는 시안과 달리, 실제 글 본문과 절 단위 이동, 다음 기록 탐색까지 연결됩니다.”

### 4. 키보드와 좁은 화면

- 홈에서 Tab으로 필터에 이동해 포커스 테두리를 보여 주고 Enter로 Handgun을 선택합니다.
- 브라우저 모바일 에뮬레이션을 375px, 320px로 바꿔 목록과 썸네일을 보여 줍니다. 확인 기록상 두 폭 모두 가로 넘침이 없습니다.
- 한계를 함께 설명합니다. 320px에서는 본문 목차가 숨겨지고, 홈 썸네일에는 대체 텍스트가 없습니다. 이번 결과물은 기존 블로그를 그대로 사용해 이 부분을 수정하지 않았습니다.

### 5. 사용자 테스트와 기록

- 제작자인 사용자가 실제 블로그에서 최근 글 열기, 목차로 절 이동 후 목록 복귀, Handgun 필터와 썸네일 확인을 수행했고 “다 괜찮은데?”라고 보고한 점을 설명합니다.
- 이 결과는 제작자의 직접 테스트입니다. 처음 방문한 독자의 독립 테스트와 혼동하지 않습니다.
- 마지막으로 [기획서 수정본](기획서_수정본.md), [제작·검증 기록](제작검증기록_수정본.md), [브라우저 검증 근거](evidence/기존기술블로그_브라우저검증_2026-11-09.md)를 보여 줍니다.

## 말할 때 구분할 점

- 기존 블로그가 실제 결과물이라는 점과, 이번 세션에서 온라인 사이트를 수정하지 않았다는 점을 구분합니다.
- 저장소에는 블로그의 배포 소스나 배포 커밋이 없으므로, v1에서 현재 사이트까지의 연결 과정은 사용자가 설명한 작업 맥락으로 말합니다. Git 기록이 배포 과정을 증명한다고 설명하지 않습니다.
- 브라우저 에뮬레이션은 실제 휴대폰 검증이 아닙니다. 제작자 테스트는 독립적인 첫 방문자 테스트가 아닙니다.
