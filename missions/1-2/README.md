# 미션 1-2: 오류를 재현하고, 본 대로 물어서 고치기

## 목표

`기획서.md`의 완성 기준을 직접 확인해 문제를 좁히고, AI에게 원인 설명을 먼저 요청합니다. 설명이 맞는지 브라우저에서 확인한 뒤에만 문제 하나를 고칩니다.

## 현재 상태

- 제공된 `영화_수정전.html`과 `기획서.md`를 이 폴더로 정리했습니다.
- `영화_수정전.html`은 원본으로 보존했으며 아직 열어 보거나 수정하지 않았습니다.
- 사용자가 첫 두 카드는 옮겼고, 세 번째 카드부터 끌어 놓기가 잘 반영되지 않는다고 보고했습니다.
- 미분류 카드를 등급으로 끌어 옮겨도 다시 미분류로 돌아오는 증상이 보고되었습니다.
- 사용자는 특정 영화 제목이나 등급과 관계없이 이동이 잘 작동하지 않는다고 보고했습니다.
- 카드 클릭도 간헐적으로 반응하지 않으며, 잠시 기다린 뒤에는 클릭과 드래그가 작동한다고 보고했습니다.
- 기다리는 시점과 시간, 같은 입력을 반복했을 때의 결과는 아직 분리해 확인하지 않았습니다.

## 진행 순서

1. 브라우저에서 `영화_수정전.html`을 열고 ‘처음으로’를 누릅니다.
2. 기획서의 완성 기준을 확인하고, 기본 영화 8편을 빠짐없이 옮겨 봅니다.
3. 실패한 경우 제목·동작 방식·대상 등급을 기록하고 같은 행동을 다시 해 재현 여부를 확인합니다.
4. 영화 제목이나 동작 방식에 따라 결과가 달라지는지 비교해 증상을 한 문장으로 좁힙니다.
5. AI에게 원인 설명과 확인 방법만 묻습니다. 설명이 맞는지 브라우저에서 시험하기 전에는 파일을 고치지 않습니다.
6. 원인이 확인되면 문제 하나만 고치고 `영화_수정1.html`로 저장합니다. 원본은 유지합니다.
7. 같은 조건으로 실패한 영화, 새 영화, 정상 동작하던 영화, 저장, 초기화를 다시 확인합니다.

## 다음 할 일

파일을 연 뒤 입력하기까지의 대기 시간이 결과에 영향을 주는지 분리해 확인합니다. 바로 시도한 결과와 기다린 뒤 같은 동작을 한 결과를 기록합니다. 수정은 재현 조건을 좁히고 원인 설명을 확인한 뒤 시작합니다.

## 파일

- `기획서.md`: 1-2에서 사용할 완성 기준
- `영화_수정전.html`: 보존해야 할 제공 원본
- `미션2_기록.md`: 재현, 원인 확인, 수정 결과 기록
- `references/`: 제공된 세션 참고 자료
- `evidence/`: AI 대화 캡처
