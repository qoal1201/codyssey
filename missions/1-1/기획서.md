# 영화 티어리스트 기획서

## 누가 쓰나

- 사용자와 영화 친구들이 한 기기를 함께 보며 사용합니다.

## 무엇을 하려고

- 친구들과 영화 이야기를 나누며 영화들을 S·A·B·C·D 등급으로 함께 분류합니다.

## 화면과 동작

- 기본 영화 8편을 제목 카드로 보여 줍니다. 포스터 이미지는 넣지 않습니다.
- S·A·B·C·D 등급과 미분류 영역을 세로로 쌓인 행 6개로 보여 줍니다.
- 카드를 끌어다 놓아 등급 사이로 옮깁니다.
- 새 영화 제목을 입력해 추가하면 미분류 영역에 놓입니다.
- 영화 목록과 등급 배치를 같은 브라우저에 자동 저장합니다.
- ‘처음으로’를 누르면 직접 추가한 영화는 지우고, 기본 영화 8편을 미분류로 되돌립니다.

## 필요한 자료

- 기본 영화 목록: 기생충, 인터스텔라, 라라랜드, 센과 치히로의 행방불명, 어벤져스: 엔드게임, 범죄도시, 타이타닉, 토이 스토리
- 사용자가 추가할 영화 제목

## 완성 기준

- 기본 영화 카드를 미분류에서 S·A·B·C·D 각 영역으로 끌어다 놓을 수 있습니다.
- 영화 카드는 한 번에 한 영역에만 나타납니다.
- 새 영화 제목을 추가하면 미분류 영역에 카드가 나타납니다.
- 같은 HTML 파일을 같은 브라우저에서 다시 열면 영화 목록과 등급 배치가 남아 있습니다.
- ‘처음으로’를 누르면 직접 추가한 영화가 사라지고 기본 영화 8편이 미분류로 돌아옵니다.
- 외부 파일이나 서버 없이 HTML 파일 하나를 브라우저에서 열어 사용할 수 있습니다.

## 아직 정하지 않은 점

- 같은 제목을 여러 번 추가할 수 있는지
