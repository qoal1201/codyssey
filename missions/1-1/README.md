# 미션 1-1: 영화 티어리스트

## 목표

AI가 먼저 질문하게 해 요구사항을 정하고, 같은 기획서로 만든 두 HTML 결과물을 같은 행동으로 비교합니다.

## 현재 상태

- 기획서와 AI A 초안(Codex)이 준비되어 있습니다.
- 사용자가 AI A의 수동 확인을 마쳤다고 보고했습니다. 항목별 결과는 아직 기록되지 않았습니다.
- AI B 초안은 Gemini 3 Flash가 만들었고 `영화_B_초안.html`로 정리했습니다.
- Gemini 대화 캡처를 `evidence/`에 보관했습니다.
- AI B의 수동 확인, 두 결과의 비교, 최종 선택과 기록은 남아 있습니다.

## 다음 할 일

1. AI B에서 기본 영화 이동, 새 제목 추가, 같은 브라우저에서 다시 열기, 초기화를 확인합니다.
2. A와 B의 같은 행동 결과를 `미션1_기록.md`에 기록합니다.
3. 이어서 사용할 결과를 선택합니다. 수정이 필요하면 초안을 보존하고 별도 수정본으로 만듭니다.
4. 제출 전에 캡처에 불필요한 개인정보나 대화가 보이지 않는지 확인합니다.

## 파일

- `기획서.md`: 결정한 요구사항
- `영화_A_초안.html`: Codex가 만든 첫 초안
- `영화_B_초안.html`: Gemini 3 Flash가 만든 첫 초안
- `미션1_기록.md`: AI 정보, 비교 결과, 선택 및 수정 기록
- `references/`: 제공된 아이디어, 예시 기획서, 코랩 세션 리포트
- `evidence/`: 주요 대화 캡처
