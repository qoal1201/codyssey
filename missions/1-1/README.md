# 미션 1-1: 영화 티어리스트

## 목표

AI가 먼저 질문하게 해 요구사항을 정하고, 같은 기획서로 만든 두 HTML 결과물을 같은 행동으로 비교합니다.

## 현재 상태

- 기획서와 AI A 초안(Codex)이 준비되어 있습니다.
- 사용자가 AI A와 AI B의 수동 확인을 마쳤다고 보고했습니다. 항목별 결과는 아직 기록되지 않았습니다.
- AI B 초안은 Gemini 3 Flash가 만들었고 `영화_B_초안.html`로 정리했습니다.
- Codex와 Gemini의 대화 캡처를 `evidence/`에 보관했습니다.
- 사용자는 B에서 기획서와 다른 동작을 발견하지 않았다고 보고했습니다.
- 사용자는 화면 구성과 디자인을 이유로 AI A를 선택했습니다.
- 행동별 상세 확인 결과는 아직 기록되지 않았습니다.

## 다음 할 일

1. A와 B의 항목별 확인 결과를 기억나는 범위에서 `미션1_기록.md`에 보충합니다.
2. 제출 전에 캡처에 불필요한 개인정보나 대화가 보이지 않는지 확인합니다.

## 파일

- `기획서.md`: 결정한 요구사항
- `영화_A_초안.html`: Codex가 만든 첫 초안
- `영화_B_초안.html`: Gemini 3 Flash가 만든 첫 초안
- `미션1_기록.md`: AI 정보, 비교 결과, 선택 및 수정 기록
- `references/`: 제공된 아이디어, 예시 기획서, 코랩 세션 리포트
- `evidence/`: 주요 대화 캡처
