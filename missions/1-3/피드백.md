# 민수 님께 드리는 피드백

잘된 점: 등급별 색으로 S·A·B·C를 구분하기 쉬웠고, 진행 개수와 드래그 중 바뀌는 칸 색 덕분에 현재 상태와 놓을 위치를 알 수 있었어요.

고치면 좋을 점

1. **본 것:** 같은 브라우저에서 파일을 닫았다가 다시 열었더니 영화의 등급 배치가 초기화됐어요.<br>
   **기준:** 기획서에는 같은 브라우저에서 다시 열어도 영화와 등급이 남는다고 되어 있어요.<br>
   **제안:** 영화 목록과 등급 배치를 브라우저에 저장해 주세요.

2. **본 것:** 화면 폭을 좁히니 오른쪽 내용이 잘렸어요.<br>
   **기준:** 좁은 화면에서도 오른쪽이 잘리지 않고 내용을 볼 수 있어야 해요.<br>
   **제안:** 좁은 화면에서도 내용을 읽고 조작할 수 있도록 화면 배치를 조정해 주세요.

3. 영화 포스터 이미지가 함께 있으면 영화의 분위기를 떠올리며 티어를 정리하는 데 더 몰입하고 집중할 수 있을 것 같아요. 포스터를 함께 보여 주는 방법도 검토해 주세요.
