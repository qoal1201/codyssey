# 미션 1-4: 기능 추가와 복구

## 목표

정상 작동하는 영화 티어리스트에 기능 하나를 더하고, 새 기능과 기존 기능을 모두 확인합니다. 기존 기능이 망가지면 수정을 계속 덧붙이지 않고 원본에서 다시 시작합니다.

## 현재 상태

- 사용자는 제공된 원본을 기준서와 함께 확인한 결과, 전반적으로 정상 작동한다고 보고했습니다.
- 원본 HTML과 제공된 기획서는 변경하지 않았습니다.
- 추가할 기능과 그 기능의 완성 기준은 아직 정하지 않았습니다.

## 다음 순서

1. 추가할 기능 하나를 고르고 성공 기준을 기획서 사본 끝에 적습니다.
2. 원본 HTML과 기획서를 바탕으로 새 기능을 요청합니다.
3. 받은 파일은 `영화_기능추가.html`로 저장하고 새 기능과 기존 기능을 처음부터 확인합니다.
4. 새 기능만 틀리면 별도 수정본을 만듭니다. 기존 기능이 깨지면 원본으로 돌아가 새 대화에서 다시 요청합니다.

## 파일

- `기획서.md`: 기능을 고른 뒤 완성 기준을 추가할 작업용 사본
- `미션4_기록.md`: AI, 추가 기능, 받은 파일별 확인과 조치 기록
- `영화_기능추가*.html`: AI가 만든 판과 수정 판
- 제공된 `기획서.md`와 `영화_원본.html`: 하위 샘플 폴더의 원본으로 보존
