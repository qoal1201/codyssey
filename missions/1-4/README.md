# 미션 1-4: 기능 추가와 복구

## 목표

정상 작동하는 영화 티어리스트에 기능 하나를 더하고, 새 기능과 기존 기능을 모두 확인합니다. 기존 기능이 망가지면 수정을 계속 덧붙이지 않고 원본에서 다시 시작합니다.

## 현재 상태

- 사용자는 제공된 원본을 기준서와 함께 확인한 결과, 전반적으로 정상 작동한다고 보고했습니다.
- 제공된 원본 HTML과 기획서는 `references/`에 보존하고, `기획서.md`는 작업용 사본으로 사용합니다.
- 사용자가 추가 기능으로 ‘칸별 영화 개수’를 선택했고, 동작별 완성 기준을 `기획서.md` 끝에 기록했습니다.
- 원본을 복사한 `영화_기능추가.html`을 만들었습니다.
- 사용자는 후보 파일을 기준에 따라 직접 확인했고, 모든 항목이 통과했다고 보고했습니다. Codex는 정적 점검만 수행했으며, 브라우저 화면을 직접 관찰하지 않았습니다.

## 확인 결과

- 칸별 개수와 기존 동작의 전체 기준을 사용자가 직접 확인해 통과했다고 보고했습니다.
- JavaScript 문법 파싱과 외부 파일 참조 여부를 정적으로 확인했습니다.
- 실패 보고가 없어 별도 수정본이나 원본 복귀는 없습니다.

## 파일

- `기획서.md`: 선택한 기능과 완성 기준을 적은 작업용 사본
- `미션4_기록.md`: AI, 추가 기능, 받은 파일별 확인과 조치 기록
- `영화_기능추가*.html`: AI가 만든 판과 수정 판
- `references/`: 제공된 기획서, 원본 HTML, 코랩 세션 리포트를 보존
